      Auto-equip (UI automation) — read before enabling
      ⚠ This is automation of the game client. It opens the same picker screens you would, finds your owned copy in the list the game loaded, and presses the item and the Equip button for you, with human-like pauses. It never calls the game's API directly — but it is still a tool operating the game on your behalf, which Cygames' Terms of Service prohibit. Accounts have been banned for client-side tools before. Nobody outside Cygames knows where their line is. Use at your own risk; if in doubt, use the Open buttons above and tap Equip yourself.

        Recording

        ● in the top bar, F9 in the game, or the tray menu starts/stops. Captures only the game view — not the sidebar or your desktop — and keeps recording while the window is minimized or in the tray. Saved to Videos\GBF Desktop as MP4 (or WebM if MP4 encoding isn't available). Quitting mid-recording finalizes the file first.

        Network

        Only the game session is proxied — the rest of your PC is untouched. Mudfish note: its normal (TUN) mode already captures the wrapper's game traffic automatically, no proxy needed here; use this only for Mudfish's SOCKS5 mode or another local proxy/VPN gateway. The ping readout above measures through whatever path is active.

        Mudfishchecking…

        Mudfish's client is a local web dashboard — this opens it in a wrapper window (node picking, GBF item, Advanced Mode paths, all of it). Launch starts Mudfish if it isn't running (expect a Windows admin prompt — it installs a network driver) and pops the console here once it's up. Saved credentials are encrypted with Windows DPAPI, used only to sign into the local console at 127.0.0.1, and auto-filled when its sign-in page appears; save with both fields empty to clear. Watch the ping readout to compare paths.

        SkyLeap mode

        Community trick (documented on gbf.wiki): the game treats you as SkyLeap — you earn SkyLeap points on desktop, the game's own sidebar disappears, and pages reportedly load a bit faster. Caveats: it redraws the whole game and can lag on some setups (just toggle it back off); logins always use the normal Chrome identity, so signing in keeps working. Same grey-area status as auto-refresh: unofficial, at your own discretion.

        Battle: auto-refresh

        Reloads the game the instant the server has applied your action — same as pressing F5 after attacking, just automatic. It does not play for you. With variance > 0, each refresh waits the floor plus a random amount (bell-shaped, so it clusters near the middle like a real reaction rather than a fixed machine tick) — this removes the tell-tale identical timing. e.g. delay 150 + variance 250 → most refreshes land ~250–350 ms out, none exactly alike. With the Full-Auto option checked (default), the wrapper reads the game's own auto-attack state and skips the reload while FA is running — so enabling refresh no longer stops FA; it simply stands down until FA ends. ⚠ Refresh tools are a grey area under Cygames' terms; use at your own discretion.

        Accounts

        Each account is a fully separate login (own cookie jar). Picking one switches the game immediately — log in via the game's login screen the first time. Extra game windows (⧉) open as whichever account is active.

        Session

        Login popups (Mobage, Google, Yahoo, DMM…) open inside the app and share the game's cookie jar. If login loops, clear cookies and try again.

        Shortcuts: F5 reload · F9 record · Ctrl+B hide/show sidebar (hidden = thin rail on the left; click it to bring the sidebar back — also in the tray menu) · Ctrl +/−/0 zoom · Ctrl+Shift+G show window from anywhere.
